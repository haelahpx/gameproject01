# SEMESTER RECEH — Cerita, Struktur Minggu, Event & Humor

## 1. Premis & Target Hidup
Kamu merantau dari kota kecil ke kota besar untuk kuliah di **Universitas Nusa Receh (UNR)**. Orang tua melepasmu dengan satu pesan: *"Yang penting lulus, Nak."* Uang saku terbatas, kos sempit, kampus penuh kejadian aneh. Tidak ada penjahat dan tidak ada misi penyelamatan dunia. Konfliknya adalah bertahan, berkembang, dan menikmati satu semester pertama.

### Target Hidup ("Janji Semester")
Dipilih di awal permainan. Membuat arah main terasa personal dan memengaruhi dialog serta ending (pemain tetap bebas melakukan apa saja).

| Janji Semester | Tujuan | Cocok untuk Gaya Main |
| :--- | :--- | :--- |
| **Anak Rajin** | $\text{IPK akhir} \ge 3,50$ | Fokus akademik |
| **Anak Gaul** | 3 teman di tingkat 4 hati | Fokus sosial dan cinta |
| **Anak Mandiri** | Tabungan $\ge \text{Rp}1.500.000$ & kamar "Estetik" | Fokus uang dan dekorasi |
| **Anak Organisasi** | Terpilih jadi ketua himpunan | Fokus reputasi |

## 2. Struktur Cerita: 6 Minggu Game
Cerita bersifat semi-terstruktur: tiap minggu punya satu "kejadian utama" yang pasti terjadi, sementara sisanya event acak dan pilihan pemain.

| Minggu | Tema | Kejadian Utama (Terjamin) | Yang Diperkenalkan |
| :-: | :--- | :--- | :--- |
| **1** | **Ospek dan Adaptasi** | Hari pertama: kenalan dengan Bu Tini dan Bagas, kelas pertama Pak Darmawan | Gerak, interaksi, kelas, tidur, HP |
| **2** | **Cari Duit dan Teman** | Mang Ujang butuh pegawai; Kak Rey mengajak ikut himpunan; tugas kelompok pertama | Kerja part-time, tugas, organisasi (gabung) |
| **3** | **Akhir Bulan Pertama** | UTS; tagihan kos; Bagas ngajak nongkrong saat uang tipis | Ujian, drama akhir bulan, belanja |
| **4** | **Pekan Raya Kampus** | Proposal acara direvisi berkali-kali; lomba makan mi; persiapan panitia | Proposal, panitia, event absurd |
| **5** | **Puncak dan Krisis** | Hari H Pekan Raya; ujian kejutan; peluang ajak jadian | Event besar, romansa, tekanan deadline |
| **6** | **Penutup Semester** | UAS; tagihan kos kedua; pemilihan ketua; malam perpisahan semester | Ujian akhir, ending, rapor hidup |

### Alur Emosi Cerita
* **Minggu 1:** Canggung dan lucu $\rightarrow$ **Minggu 2:** Mulai nyaman $\rightarrow$ **Minggu 3:** Tekanan pertama (uang, UTS) $\rightarrow$ **Minggu 4:** Seru dan kacau (acara kampus) $\rightarrow$ **Minggu 5:** Puncak dan krisis $\rightarrow$ **Minggu 6:** Refleksi, hasil, syukuran kecil.
* **Kata Kunci Arah Emosi:** Dari *"aku kangen rumah"* menuju *"ternyata aku punya tempat di sini."*

## 3. Tutorial di Dalam Cerita (Minggu 1)
Tutorial dibagi 6 langkah kecil, dipandu Bu Tini dan Bagas, tanpa layar penjelasan panjang. Tiap langkah muncul sekali dan bisa dibuka lagi di HP tab Bantuan.

| Hari | Langkah Cerita | Mekanik yang Diajarkan |
| :-: | :--- | :--- |
| **1** | Bangun, keluar kamar, kenalan dengan Bu Tini | Gerak (`WASD`), kamera, interaksi (`E`) |
| **1** | Buka HP untuk lihat tujuan | HP (`Tab`), "Tujuan Hari Ini" |
| **1** | Masuk kelas pertama | Sikap di kelas (Fokus/Santai/Tidur) |
| **2** | Makan dan tidur | Energi, makan di warung/kos, tidur |
| **3** | Beli satu barang di BelanjaKu | Belanja lewat HP, sistem paket besok pagi |
| **4** | Taruh barang di kamar | Mode dekor (taruh, putar `R`, batal) |

## 4. Ending: "Rapor Hidup"
Setelah hari ke-36 berakhir, game menampilkan **Rapor Hidup** (satu layar ringkas):

| Kategori | Dinilai Dari | Nilai |
| :--- | :--- | :--- |
| **Akademik** | IPK Akhir | S / A / B / C |
| **Dompet** | Uang akhir + Kenyamanan kamar | S / A / B / C |
| **Pertemanan** | Total hati teman | S / A / B / C |
| **Reputasi** | Reputasi dan jabatan organisasi | S / A / B / C |

### Daftar Gelar Akhir
Pemain bisa mendapat lebih dari satu gelar (ditampilkan yang tertinggi plus daftar sisanya):
* **Cumlaude Sejati:** $\text{IPK} \ge 3,50$
* **Ketua Legendaris:** Terpilih jadi ketua himpunan
* **Sultan Kos:** $\text{Kenyamanan kamar} \ge 40$ dan $\text{uang} \ge \text{Rp}1.500.000$
* **Raja/Ratu Nongkrong:** 3 teman di 4 hati atau lebih
* **Pasangan Kampus:** Berpacaran di akhir semester
* **Bertahan Hidup:** Menamatkan semester (gelar dasar, semua orang dapat)
* **Mahasiswa Abadi:** $\text{IPK} < 2,00$ (versi lucu, bukan hukuman: ada epilog *"semester depan kita coba lagi"*)

* **Epilog & Jurnal:** Slideshow singkat ($3\text{--}5$ kartu gambar/teks) berisi momen yang pemain alami dari Jurnal otomatis. Jika "Janji Semester" tercapai, muncul tambahan 1 baris epilog khusus dan 1 pencapaian.

## 5. Gaya Humor, Running Gag & Contoh Dialog
* **Gaya Humor:** Bersumber dari situasi, bukan lelucon panjang. Teks pendek (maks 2 baris), nada santai, bahasa sehari-hari.
* **Running Gag (Diulang agar jadi identitas):** WiFi kos lemot, token listrik habis, mi instan raib, *"revisi lagi"*, gorengan selalu tinggal satu, alarm yang tidak bunyi.

**Contoh Dialog:**
* **Bu Tini:** *"Nak, kos tanggal berapa? Ibu nggak nagih kok. Ibu cuma mengingatkan... dengan sangat keras."*
* **Bagas:** *"Cuma 15 ribu doang, Bro. Besok juga ada uang. Eh... ada nggak ya?"*
* **Pak Darmawan:** *"Kuis dadakan. Kenapa dadakan? Karena hidup juga dadakan."*
* **Kak Rey (rapat):** *"Oke, kita sudah sepakat. Tinggal... diskusi lagi warnanya."*
* **Pak Pembina (proposal):** *"Bagus sekali. Tinggal ganti font, warna, judul, dan tujuan acara."*

## 6. Sistem Event & Pool 20 Event Awal
### Aturan Event Acak
* Maksimal 1 event negatif per hari.
* Minimal 1 event positif tiap 2 hari.
* Tidak ada event acak pada hari ujian (UTS/UAS) dan hari akhir pekan pertama.
* Format tiap event: Dialog singkat + 2 pilihan tombol + perubahan stat.
